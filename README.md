# Angelo Ang — Portfolio

Personal portfolio built with **React 19**, **Vite**, and **GSAP** (`@gsap/react` + `ScrollTrigger`).

## Features
- **Hero** — Staggered headline reveal and ambient glow animation
- **About** — Bio and background with directional scroll reveal
- **Skills & Toolkit** — Categorized tech stack cards animated with `ScrollTrigger.batch`
- **Selected Projects** — Interactive 3D tilt cards, cursor-following badge, and FLIP-style GSAP lightbox
- **Responsive Navigation** — Scroll-spy active link highlighting and accessible mobile menu
- **Reduced Motion Support** — Respects `prefers-reduced-motion` across all GSAP and CSS animations

## Getting Started

```bash
npm install
npm run dev
```

## Scripts
- `npm run dev` — Start development server
- `npm run build` — Build for production
- `npm run preview` — Preview production build
- `npm run lint` — Run Oxlint
